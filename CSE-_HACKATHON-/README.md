## 🚀 Quick Commands

### Backup
```bash
mkdir -p backups/$(date +%Y%m%d_%H%M%S)
cp -r client backups/
cp -r server backups/
```

### Update Frontend
```bash
cp App_IMPROVED.jsx client/src/App.jsx
cp styles_IMPROVED.css client/src/styles.css
cp Login_IMPROVED.jsx client/src/pages/Login.jsx
cp Register_IMPROVED.jsx client/src/pages/Register.jsx
cp Landing_NEW.jsx client/src/pages/Landing.jsx
cp NotFound_NEW.jsx client/src/pages/NotFound.jsx
```

### Install Dependencies
```bash
cd client
npm install react-icons --save
```

### Test
```bash
npm run dev
# Visit http://localhost:5173/
```

### Build
```bash
npm run build
```
